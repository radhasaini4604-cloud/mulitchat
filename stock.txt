=============================================
SMOOTH HEIGHT ACCORDION TRANSITION CODE
=============================================

How it works:
To transition height dynamically from 0 to auto without hardcoding max-height,
we use CSS Grid `grid-template-rows` transitioning from `0fr` to `1fr`.
Inside the grid container, we wrap everything in an element with `min-height: 0`.

CSS Code:
---------------------------------------------
/* Parent Row Wrapper */
.role-row-item {
  display: flex;
  flex-direction: column;
  align-items: stretch;
  transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1);
}

/* Accordion details container */
.role-row-details {
  display: grid;
  grid-template-rows: 0fr;
  transition: grid-template-rows 0.4s cubic-bezier(0.16, 1, 0.3, 1), opacity 0.3s ease, margin 0.4s ease, padding 0.4s ease;
  opacity: 0;
  overflow: hidden;
}

/* Expanded state class */
.role-row-item.expanded .role-row-details {
  grid-template-rows: 1fr;
  opacity: 1;
  margin-top: 18px;
  padding-top: 18px;
  border-top: 1px dashed rgba(255, 255, 255, 0.08);
}

/* Crucial inner wrapper (forces grid row calculation) */
.role-details-inner {
  min-height: 0;
}


React TSX structure:
---------------------------------------------
const [expandedRoleId, setExpandedRoleId] = useState<string | null>(null);

return (
  <div 
    className={`role-row-item ${expandedRoleId === role.id ? 'expanded' : ''}`}
    onClick={() => setExpandedRoleId(expandedRoleId === role.id ? null : role.id)}
  >
    <div className="role-row-main-header">
      <span>Role Title</span>
      <span className={`role-arrow-icon ${expandedRoleId === role.id ? 'rotated' : ''}`}>
        ▼
      </span>
    </div>

    {/* Transition container */}
    <div className="role-row-details">
      {/* Inner container with min-height: 0 */}
      <div className="role-details-inner">
        <p>Focus requirements and description text...</p>
        <button onClick={(e) => e.stopPropagation()}>
          Apply Now
        </button>
      </div>
    </div>
  </div>
);

APPLE LIQUID GLASSMORPHISM & SPECULAR 3D DEPTH
=============================================

How it works:
Combines backdrop-filter frosted blur with specular top highlights (`0 1px 0 rgba(...) inset`) 
and deep ambient drop shadows to create authentic 3D VisionOS / macOS liquid glass UI.

---------------------------------------------
