Interactive SVG Graph Editor

Select a model, drag existing circles to reposition points, double-click on the black area to add a new point, or select a circle and press "Delete" to remove it. Copy the generated code at the bottom when you're satisfied!

Hotkeys:
• Double click on black canvas to add point at cursor X.
• Click point + press "Delete" key to remove point.
• Drag circle handles to move points.
• Dragging is restricted to standard chart bounds.
